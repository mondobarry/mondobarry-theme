== Description ==

Thème WordPress custom one-page pour portfolio professionnel.
Design dark premium avec terminal animé, grille de compétences, projets, timeline expérience et section infrastructure homelab.

Panneau de réglages complet via Apparence → Personnaliser :
- Polices (Geist, Inter, Space Grotesk, et plus — Google Fonts)
- Couleurs (accent, fond, cartes, texte)
- Contenu hero (badge, titre 3 lignes, sous-titre, stack, boutons)
- Photo de profil
- Liens sociaux (email, LinkedIn, GitHub)
- Sections visibles/cachées
- Formulaire de contact avec envoi AJAX
- Tracking : Google Analytics 4, Google Tag Manager, AdSense, Facebook Pixel

== Installation ==

1. Téléverser le dossier mondobarry-theme dans /wp-content/themes/
2. Activer le thème depuis Apparence → Thèmes
3. Personnaliser via Apparence → Personnaliser → 🎨 MondoBarry — Réglages
